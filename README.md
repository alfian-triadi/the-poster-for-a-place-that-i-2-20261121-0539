A travel poster for **VELMORA** — a floating island above a sea of clouds at
sunset, with a white lighthouse tower, cypress trees, waterfalls pouring off
the island's edges, and smaller islets drifting nearby. Velmora does not
exist, which is exactly the point.

The poster is drawn entirely procedurally by `main.py` using only the Python
standard library: no network, no downloaded assets, no fonts from disk. The
place name is rendered from an embedded block-letter font, so the program
runs identically in any sandbox.

## Run it

```sh
python3 main.py
```

Writes a 1024×1024 PNG to `/output/entry.png` (about 100 KB, well under the
1 MiB cap). Runs in about 5 seconds.
